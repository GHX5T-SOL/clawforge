# NexaPersona Labs - Founder Strategy Hub

Interactive internal web app for `Ghost` and `Zoro` that unifies:
- business plan
- market research
- technical blueprint
- execution roadmap
- investor narrative
- interactive mock swarm dashboard

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy (Vercel)

`vercel.json` is included and configured for Vite:
- build command: `npm run build`
- output directory: `dist`

## Key Files

- `src/App.tsx` - main interactive application
- `src/data/mockData.ts` - unified strategy, research, and dashboard mock data
- `src/styles.css` - UI styles
- `docs/UNIFIED_NEXAPERSONA_PLAN.md` - merged plan synthesis from all reviewed plans
